# PraX OSINT Telegram Bot - Vercel Deployment

## Prerequisites

- [Vercel Account](https://vercel.com/signup)
- [Vercel CLI](https://vercel.com/docs/cli) installed
- Telegram Bot Token from [@BotFather](https://t.me/BotFather)

## Project Structure

```
project/
├── api/
│ └── index.py        # Vercel serverless function (webhook handler)
├── bot.py            # Main bot logic (imports here)
├── requirements.txt  # Python dependencies
├── vercel.json       # Vercel configuration
├── .gitignore
└── README.md
```

## Environment Variables

Set these in your Vercel project settings (or link to secrets):

| Variable     | Description                                    | Example |
|--------------|------------------------------------------------|---------|
| `BOT_TOKEN`  | Telegram Bot Token from BotFather              | `123456:ABC...` |
| `API_URL`    | External API URL for number lookup             | `https://astha-9vd8.onrender.com/tapi-...` |
| `BOT_NAME`   | Display name for your bot                      | `PraX OSINT` |
| `WEBHOOK_URL`| Auto-generated by Vercel after first deploy    | `https://your-project.vercel.app/api/index` |

## Deployment Steps

### 1. Install Vercel CLI

```bash
npm install -g vercel
```

### 2. Login to Vercel

```bash
vercel login
```

### 3. Link Project (if not already)

```bash
vercel link
```

### 4. Set Environment Variables

```bash
# Set your Telegram bot token
vercel env add BOT_TOKEN

# The API URL is pre-configured, but you can override it
# vercel env add API_URL

# Set webhook URL (will be your deployed app URL + /api/index)
# Example: https://your-project-name.vercel.app/api/index
vercel env add WEBHOOK_URL
```

### 5. Deploy

```bash
vercel
```

### 6. Set Webhook Manually (if auto-setup fails)

After deployment, set the webhook using curl:

```bash
curl "https://api.telegram.org/botYOUR_BOT_TOKEN/setWebhook?url=https://your-project-name.vercel.app/api/index"
```

## Testing

Once deployed, you should see:
1. Webhook successfully set in Vercel logs
2. Bot responds to `/start` command on Telegram
3. Sending a 10-digit Indian number returns formatted results

## Notes

- This deployment uses **webhooks** instead of polling (required for serverless)
- The webhook URL is typically your Vercel deployment URL + `/api/index`
- Each function invocation creates a new event loop, so state isn't preserved between calls
- Cold starts may cause slight delays on first request after inactivity
